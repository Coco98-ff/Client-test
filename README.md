# GestiStock Pro

GestiStock Pro est une application SaaS moderne de gestion de stock développée par Irex Digital.

## Fonctionnalités

- Authentification sécurisée
- Gestion des produits
- Gestion des catégories
- Gestion des fournisseurs
- Gestion des dépôts
- Entrées et sorties de stock
- Tableau de bord avec statistiques
- Alertes de stock faible
- Facturation (Devis, Bons, Factures)
- Gestion des utilisateurs
- Gestion des rôles
- Paramètres de l'entreprise
- Abonnements Premium

## Technologies

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express

### Base de données
- PostgreSQL
- Prisma ORM
